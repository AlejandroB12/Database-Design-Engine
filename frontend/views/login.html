Características

Una herramienta completa que transforma SQL en diagramas visuales con edición interactiva y múltiples formatos de exportación.

SQL a Diagrama

Pega tu SQL y genera al instante el diagrama ER con tablas, columnas, PKs, FKs y cardinalidades.

Exportar PNG / PDF

Exporta tu diagrama como PNG o PDF con un clic. Ideal para documentación y presentaciones.

Generar SQL

Desde el diagrama visual genera el SQL equivalente para MySQL o PostgreSQL.

Auto Layout

Organiza tablas automáticamente con algoritmos de grafo. Ordena por nombre, color o relaciones.

Capas y Categorías

Agrupa tablas en capas de colores con categorías personalizadas.

Editor Visual

Edita con arrastrar y soltar. Añade tablas, conecta relaciones y personaliza cada elemento.
